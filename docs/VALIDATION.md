## 真实 MCP 检查

`scripts/check_mcp.py` 从合成文本开始，运行真正的后端和协议客户端。验证包括：

- 普通改编的条件编辑、框架锁定、交接、证据、设定、大纲、正文、审查和不可变版本。
- 深度重写的上版保留、结构诊断、双来源计划、九项审查与全书三方差异契约。
- 审稿来源、分页与扫描、精确证据、原子补丁、过期写入拒绝、重新复核与覆盖。
- 人物、关系、知情记录、冻结后的只读完整性审计，以及七种文件的实际下载核验。
- 精修版再审、接续深改，以及新 STDIO 进程恢复同一版本。

当前本地 STDIO 发现40个工具；远程 HTTP 不暴露本机文件路径导入。

## 验证边界

工程测试与协议样本检查契约、权限、修订、数据链和交付行为，不是长篇小说的文学质量、模型理解或自动审稿准确率评测。

此次发布未执行实际公网域名的 DNS / TLS 签发、大规模负载、跨服务器共享存储或全套浏览器交互复测。Docker 构建与 Compose 配置通过也不等于已经部署网站；生产部署步骤见 [部署说明](multi-user-deployment.md)。
