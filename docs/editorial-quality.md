# 文字质检与精修设计

网页、HTTP API 与 `novelstudio` MCP 共用 `Editorials` 应用服务。Codex 负责实际阅读和文学判断；服务负责范围、当前正文、证据、版本、问题状态与导出校验。

## 审稿来源与范围

从冻结的普通改编、完整译稿、深度重写或指定精修版本建立独立会话，固定来源指纹、章节范围、审读深度和修改权限。保留原版与旧结论；新版本拥有自己的证据和覆盖。

| 模式 | 约定 |
| --- | --- |
| scan | 对所选全文运行规则，返回候选，不提供文学结论 |
| focused | 全量扫描，逐章首尾与风险、关键场景的重点语义复核 |
| full | 逐块阅读所选全部正文，并完成跨章审查 |

正文分页最多6000个 Unicode 码点／24个片段，长段继续分块。游标与正文修订绑定；问题与记录分页还绑定会话修订及筛选条件。读取一块长段不能算读完该整段。

## 证据、修改与复核

- 证据包含来源、章段、当前正文指纹、Unicode 码点区间与逐字引文。
- `locate_editorial_evidence` 可直达证据所在块，区分当前准确匹配、只有文字相同和旧版本过期。
- `report.kind="findings"` 只登记局部问题，不授予整块或文学专项的阅读覆盖。
- 补丁绑定问题、原段落及改前哈希；相同段的多个候选不能在同一批应用。
- 原子应用整批校验，过期、冲突或证据错误时全部拒绝；事务失败不会留下半份修改。
- 修改后旧扫描、语义判断和故事依赖失效。复核需要比较真实改前改后与受影响后文。
- 问题保留 open / proposed / needs_recheck / resolved / dismissed / deferred 等实际状态，暂缓不等于通过。

请求回执与导出字节独立保存，避免每次修改都复制历史完整响应。写入使用最新 revision 和唯一 request_id；同键同载荷可重试，不同载荷冲突。

## 文学专项

新建非 scan 会话默认提供八项专项：模板与重复、重复解释、用词与具体性、句段节奏、意象与修辞、人物声音、对白潜台词、叙述分寸。

分块和跨章报告逐项提交结果、理由与当前证据；发现问题时关联同维度问题记录。补丁说明预期改善与保留项，修改后核对实际效果。没有改善或损伤保留项的修改不能记为复核通过。旧通用会话保留历史范围，不自动变成专项通过。

规则提供精确/近似重复段落、重复完整句、同章高密度句式和相似章首章末等候选；计算范围与跳过数量随扫描保存。普通重复、引文或有意的语言回环须结合语境判断。

## 数值与故事连续性

事实、约束与人物账本都需要正文证据：

- 年份、精确公历日期、整数数量和 Decimal 金额分别计算；区分账户、已付与未兑现、人物相信与客观事件。
- 稳定人物实体 ID 独立于显示姓名；同名不同人、别名、身份揭示和章节适用区段分别保存。
- 关系带方向、视角与有效区段；知情记录说明谁在何时通过何种证据取得信息。
- 图谱是已登记资料的派生视图，不自动证明人物关系提取完整或情节正确。
- 新建文学会话默认 tracked 逐章核对；旧会话保留原模式和限制，不靠改模式消除覆盖缺口。

上游正文、事实或实体改变时，对应关系、知情和核对状态待更新。重复提交完全相同的资料不会无故清空已完成工作。

## 版本与导出

支持独立精修版及 EPUB / TXT / Markdown / JSON / 报告 / 修订对照 / ZIP 七种导出。冻结前核对当前覆盖、未处理问题和修改后复核。结构遗留项如按约定随版本保存，候选定稿条件继续显示未满足。

导出先核验正文、段落清单及实际文件；版本与字节在同一事务保存，下载再检查保存的字节指纹。精修版可继续建立审稿或深度重写，来源链保留最初原著。

只读架构审计见 [editorial-architecture-audit.md](editorial-architecture-audit.md)。数据完整性、工程测试与文学质量是不同的结论；系统不能从接口调用证明模型理解正确，也不能自动发现从未被提取的伏笔或人物。

## 实现与验证入口

- `backend/app/editorial.py`：会话、问题、补丁、复核、冻结。
- `editorial_models.py` / `editorial_quality.py`：严格报告与专项契约。
- `editorial_text.py` / `editorial_checks.py` / `editorial_patterns.py`：指纹、码点、分页和有界规则。
- `editorial_story.py`：实体、关系、知情、依赖与逐章核对。
- `editorial_export.py` / `editorial_integrity.py`：交付与只读审计。
- `backend/tests/test_editorial*.py`：合成夹具与失败分支回归。
- `scripts/check_mcp.py`：真实 HTTP / STDIO MCP 闭环。

当前公开验证见 [VALIDATION.md](VALIDATION.md)。个人作品、本机项目 ID、审稿聊天、小说正文和私有截图不作为公开验证附件。
